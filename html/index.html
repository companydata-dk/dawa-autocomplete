Adresse-autocomplete uden DAWA

Samme widget som dawa-autocomplete2, samme forslag, samme data. Kun kilden er ny: dawa.companydata.dk. Prøv den her.

Vejnavn, så husnummer, så etage og dør. Pil ned og Enter, eller klik.

Prøv det: skriv Rentemestervej 8 med og uden det andet e. Uden fluebenet finder stavefejlen ingenting.

Det din kode får tilbage

Vælg en adresse ovenfor, så vises select-callbackens argument her.

Sådan sættes den op

<link rel="stylesheet" href="https://cdn.companydata.dk/dawa-autocomplete/2.0.0/dawa-autocomplete2.css">
<input id="adresse" type="text" autocomplete="off">
<script src="https://cdn.companydata.dk/dawa-autocomplete/2.0.0/dawa-autocomplete2.min.js"></script>
<script>
  dawaAutocomplete.dawaAutocomplete(document.getElementById('adresse'), {
    select: valgt => console.log(valgt.data.id, valgt.tekst)
  });
</script>

Eller npm install @companydata-dk/dawa-autocomplete. Bruger du allerede dawa-autocomplete2, sætter du bare baseUrl: 'https://dawa.companydata.dk'.

Flere varianter

Alle indstillinger fra dawa-autocomplete2 virker uændret. Se galleriet med adgangsadresser alene, kommunefilter, minimumslængde og de øvrige.
